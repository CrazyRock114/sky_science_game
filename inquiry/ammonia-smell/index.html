📘 G8 / IGCSE 0620 深度科学内核

1. 成分与来源：无味尿素的酶促水解

新鲜尿液本身几乎没有刺鼻氨臭，其主要含氮代谢物是无味的尿素 CO(NH₂)₂。当尿液残留于地面缝隙或便池壁时，环境细菌分泌的脲酶（Urease）催化尿素水解，持续生成挥发性氨气与二氧化碳：

CO(NH₂)₂(aq) + H₂O(l) —[Urease]→ 2NH₃(g) + CO₂(g)

2. 为何“远扬”：Mr(NH₃)=17 与 Graham 扩散速率

氨气相对分子质量 Mr(NH₃) = 14 + 3×1 = 17，显著小于空气平均相对分子质量 Mr ≈ 29。结合粒子热运动与 Graham 扩散速率定律，质量越轻的气体分子平均运动速率越快、密度更小易向上浮升，叠加走廊空气对流即可实现远距离传播。

r(NH₃) / r(Air) = √(M_air / M_NH₃) = √(29 / 17) ≈ 1.31×

3. 为何“持久”：尿垢缓释 + 1:700 水溶可逆平衡

① 便池内沉积的尿垢（磷酸钙 / 尿酸盐结晶）多孔吸液，成为细菌滋生与慢释源；② 氨气具有极高水溶性（常温 1 体积水可溶约 700 体积 NH₃），溶解在潮湿瓷砖与墙面水膜中建立弱碱平衡，随温度升高或水分蒸发反复释放；这也是 IGCSE 0620 潮湿红色石蕊试纸变蓝检验氨气的化学本质。

NH₃(g) + H₂O(l) ⇌ NH₄⁺(aq) + OH⁻(aq) (Damp red litmus → BLUE)

4. 科学除臭与致命安全铁律

使用柠檬酸等温和弱酸清洁剂，可提供 H⁺ 将挥发性碱性气体 NH₃ 中和为非挥发性铵盐离子（NH₄⁺），随水冲走彻底去味：

NH₃(aq) + H⁺(aq, from citric acid) → NH₄⁺(aq) (Non-volatile salt)

☠️ 致命安全铁律：严禁盐酸洁厕灵与 84 消毒液混用！

NaClO(aq) + 2HCl(aq) → NaCl(aq) + H₂O(l) + Cl₂(g)↑

二者混合瞬间释放剧毒黄绿色氯气（Cl₂），在密闭卫生间中吸入可造成严重肺部化学灼伤甚至危及生命！
